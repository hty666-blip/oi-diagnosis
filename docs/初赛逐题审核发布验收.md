# 初赛逐题审核与发布验收

2026-11-10。本批完成管理员逐题修订、人工审核和独立版本发布。采集的 1120 道真实题仍全部待审核，未自动批准；学生答题页面、交卷、客观判分和笔试 Agent 协作尚未接入。

## 操作流程

入口：平台管理 → 初赛题库 → 查看批次 → 核对题目。

- **题目预览**保留来源答案、冲突答案、题组程序、图片和原始标签；有修订时显示当前题干及修订答案，原始 JSON 不改写。
- **审核编辑**支持题型、J/S、分值、题干、共用材料、选项、答案、计分规则、主次知识点、解析和核对依据。标注建议须由管理员确认。
- **保存修订稿**追加修订，回到待审核，并将已有发布题下架。**审核通过并发布**生成新的固定版本，不覆盖历史版本。
- **撤下此题**要求操作说明；撤题后须先恢复待审核，再重新审核。单纯上下架使用独立状态版本，不能上架未经审核的新修订或旧版本。
- **修订记录**分页显示操作、管理员编号、说明与时间，可查看指定旧稿，不提供覆盖历史的接口。

## 发布门槛与隔离

发布要求确认教学使用范围，补齐正数分值、J/S、有效叶子知识点、解析、核对依据和操作说明。答案冲突、撤题线索、范围待核对及图片程序等重要标记必须逐项说明处理依据。

单选只能选一个有效答案；多选须引用有效选项，判断答案必须是布尔值。填空明确可接受文本，以及精确比较或仅忽略首尾空白。本批支持全对得分，不支持未知或部分给分规则；没有以 AI 猜测替代评分规则。图片限原题及题组资源，发布前验证存在性和摘要。

原始记录、修订稿与发布版分别保存，快照继续使用有界数据块。审核采用管理事务锁和预期修订号；相同请求编号重试不会新增版本，改变内容或提交旧修订返回 409。候选、历史、快照、发布和审计同事务提交，失败全部回滚。重放旧操作时返回当前状态，并标明原操作修订号，避免误报已经撤题或上架。

`/api/v1/written/questions` 仅向已登录用户返回已审核且上架的题面白名单；不返回答案、解析、答案来源链接、审核说明或原始包。图片要求当前版本，旧版本、未审核和已下架题不可从此入口读取。候选、审核、历史及上下架仍仅管理员可操作。
