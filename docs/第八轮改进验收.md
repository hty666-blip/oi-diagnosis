日期：2026-10-31。基线为第七轮与 CI 动作更新。

## 已复现问题

Python 的布尔值属于整数子类。存量 `AC` 记录若保存 `total=true, passed=1` 或 `total=1, passed=true`，原逻辑会将其识别为正式测试全部通过，允许修改核验关闭答疑。独立 PostgreSQL 回归在修复前稳定复现两项失败，合法整数记录通过。

## 修复与验收

- 执行摘要要求真正的整数，且 `0 <= passed <= total`；非对象 JSON、布尔、浮点和负数不作为测试计数展示。
- 历史 `AC` 必须具有非零、完整、一致的计数，且范围为正式题包，才可继续表示正式通过。异常或矛盾计数显示 `UNVERIFIED`（历史结果待核对）；真实零测试继续显示未验证边界。
- 详情、历史和版本链使用同一摘要；错题卡同步说明待核对。核验保留答疑，不增加失败次数；合法整数 1/1 仍可完成答疑。
- 不修改历史原始判定、计数或教师审计；不新增数据库迁移。流水线仍为 `v6`。
