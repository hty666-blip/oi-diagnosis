# 初赛按试卷练习

学生进入「初赛练习 → 试卷」。目录列出有已上架题目的试卷，显示题包登记的来源类型、级别及上架数量。不同批次的同编号卷各自独立，收录数以题包实际包含的记录计算。

打开试卷后按题包顺序读取已发布的题目，保留原题号。未上架题不会出现在列表。学生选题后沿用逐题规则评分、作答记录和错题答疑，返回时可继续当前试卷。题目更新和下架遵循现有发布规则。

试卷详情分别显示当前上架题总分、题包登记的卷面总分及分值差异。时长沿用题包标注，并显示已有来源说明。旧题包缺少这些字段时，页面只显示可确认的数据。当前采集包的 28 套卷均保留纸面时长待核对的说明，4 套旧卷的收录题分值低于标注的 100 分。

## 限时整卷模拟

完整上架、时长已登记且分值核对一致的客观题试卷可打开限时模拟。每名学生每套卷保留一份答卷，开始时固定题目版本和服务端截止时间。答题卡自动保存，刷新当前页面会直接恢复答卷，其他时候也可从「模拟记录」继续。离开页面不暂停计时。到时停止接收作答；答卷页交卷，或下次打开时结算最后保存的答案。

交卷前不提供参考答案、解析或 AI 答疑。交卷后可回看分数、作答和已审核解析；重复交卷返回同一结果。模拟分数单独保存，逐题练习和知识点掌握度不受影响。

- 桌面用 8 题、16 分的原创入门卷开始 10 分钟模拟。首题选 B 后刷新，从「模拟记录」恢复原选项与剩余时间；手动交卷，系统判为 2 / 16 分。

## 交卷后错题复练

学生交卷后在答卷的「错题复练」看到答错与未答的原卷题号。可以查看原题解析、开始复练，或者回看最近一次复练记录。复练题面加载时检查原发布版本仍有效；如果下架或换版，保留旧答卷供回看。

复练使用独立作答回执，改卷分时不会读取复练记录。普通题库的作答不能替答卷标记复练状态。返回原答卷或刷新后，仍可查看最新复练结果。复练作为实际作答可进入作答记录和学习路线；原卷成绩及答题卡不变。

迁移 `w789d30f4b60` 新增答卷与复练记录的关联；旧备份恢复时该表补空。自动演示检查包含只答对第 1 题后交卷、回练第 2 题正确、原卷仍为 2 / 16 分。

## 按知识点复习

展开已交答卷的「按知识点复习」，可按原卷题目版本查看答错和未答题号，直接阅读已发布讲义。系统从同一题包筛选同级别、同主知识点的客观题，排除本人已作答、已列入本人模拟答题卡的题目，以及题包标记的完全重复题。找不到合适题时显示「暂无新题」。

新题使用普通作答记录。完成后可以从结果页返回原卷，刷新后入口仍可用。独立 MySQL 20 项、前端 83 项与构建通过。桌面实测读讲义、答对新题和刷新后返回，原卷保持 0 / 16 分，原题仍待复练。[桌面截图](images/written-exam-study.jpg)

## 教练查看模拟学情

教练打开「初赛任务 → 模拟学情」，选择有管理权限的班级。列表显示当前启用学生已交的模拟答卷、交卷时间、原卷分数，以及原卷错题和未答题中最近一次复练答对的数量。学生转班后按当前班级归属展示。管理员可选择未归档班级。

原卷分数取自交卷时固定的答题卡。复练答对数只统计绑定同一张答卷、同一题目版本的最新复练。列表只提供汇总数据。独立 MySQL 回归覆盖未交卷、普通作答隔离、分页、转班、停用、归档及跨班拒绝访问。本功能沿用已有表，无需新迁移。

独立 MySQL 专项 18 项、前端 83 项和构建通过。使用演示账号和原创卷在桌面验收，教练看到原卷 2 / 16 分、复练答对 1 / 7 题。[桌面截图](images/written-coach-mock.jpg)

### 模拟卷单题学情

在「模拟学情」中点击任一答卷的「查看单题学情」。明细汇总当前班级同批次、同试卷的已交答卷，按原卷题号和固定题目版本列出卷内答对、答错、未答和复练答对人数。不同发布版本各列本版卷数。首次统计和复练分别取原卷答案及同答卷的最新复练记录。

独立 MySQL 专项 21 项、前端 83 项与构建通过。桌面用两份合成答卷核对，第 1 题卷内答对 1 人、未答 1 人、复练答对 1 人。第 2 题原卷答错与未答各 1 人。[桌面截图](images/written-coach-questions.jpg)

### 从单题学情布置补练

在单题学情中选仍有学生未订正、原题版本仍上架的题，点击「用所选题创建专项」。表单带入原班级和所选题目，教练可以调整名称、截止时间与选题，选择全班或指定学生，再确认发布。下架或换版的旧题保留原卷统计。发布时重新检查班级权限和选题版本。[指定学生](初赛班级专项验收.md#指定学生)

独立 MySQL 专项 23 项、前端 83 项与构建通过。桌面验证教练选择第 2 题、发布后本班模拟学生收到补练。独立数据库验证旧版被拒绝发布。[桌面截图](images/written-coach-followup.jpg)

### 预选待补练学生

在单题学情选题后，勾选「预选仍需补练的学生」。系统从本班同批次、同试卷已交的答卷中汇总名单。原卷任一所选题答错或未答且最新复练还未答对的学生进入预选。表单中可以增减名单，仍需教练确认发布。所选题下架或换版时需重新选题。

独立 MySQL 24 项、前端 83 项和构建通过。桌面验收由两份模拟答卷仅预选仍未订正的一人，取消勾选后发布按钮禁用。[预选截图](images/written-exam-audience-preview.jpg)

## 成长档案

学生在「我的档案 → 初赛练习」查看最近最多 100 次单题作答的满分和待复核次数，以及最近最多 5 份已交模拟卷的原卷分数与复练答对数。「查看答卷」打开本人的对应模拟卷。导出的训练档案使用同一汇总口径。

教练查看本人负责班级的学生档案，管理员按平台权限查看。档案只展示汇总。独立 MySQL 回归覆盖同学作答隔离、未交卷过滤、固定原卷成绩、复练统计、跨班与转班权限。前端 83 项和构建通过。桌面从学生档案打开原卷，核对原卷仍是 0 / 16 分。[桌面截图](images/student-written-profile.jpg)

## 离开答卷时的作答保护

有作答待同步时，切换侧栏或初赛标签、返回试卷、修改密码或退出，会提示留在答卷或确认离开。确认框打开时仍会保存，完成后提示可以离开。计时由服务端持续，重新打开后读取服务端已保存的答案。

通过前端 83 项和构建。用独立 MySQL 和延迟 5 秒的保存请求桌面验证，切换侧栏后选择留在答卷，答案随后保存。切换到题库时等待确认框内显示同步完成，离开并从模拟记录重开，核对答案和剩余时间。[桌面截图](images/written-exam-save-guard.jpg)
