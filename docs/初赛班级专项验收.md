# 初赛班级专项

教练从「初赛任务 → 发布专项」选择已管理的班级、填写名称和截止时间，选入最多 10 道已审核题目。默认截止时间为一周后，可在弹窗中调整。默认发布给全班启用学生，也可指定接收者。发布时固定题目顺序、版本和接收名单。管理员也可通过同一入口布置任务。

学生从「初赛练习 → 班级任务」进入专项，逐题交卷、查看解析和发起错题答疑。题库中的自由练习和专项作答分别统计，专项编号随作答保存。截止后可查看已交记录，服务器只允许重放已经保存的提交。

教练的学情表以每位学生每道题的最新专项作答为准，分别列出未交、答错和答对，并汇总全部交卷与全部答对人数。转出与停用的学生退出当前学情表，保留本人原作答记录。新转入的学生不会自动进入已发布任务。班级改名使用原班级编号和新名称。

题库发布新版时任务仍按原版本评分。题目下架后停止该题的新作答与题面读取，已有作答与评分保留。发布请求和作答请求都能凭原编号安全重试。

## 单题学情

教练在专项中展开「单题学情」，可见每题答对、答错和未交的人数。点击答错或未交人数，下方只显示这批学生。恢复后重新显示全班，本次筛选不影响班级总计。

桌面用已验收的两人班级复测。第 1 题按答错筛出提交者，第 2 题按未交筛出另一人，清除后恢复两人。前端 83 项与构建通过。[筛选截图](images/written-assignment-topic.jpg)

## 指定学生

在发布表单的「发布范围」选择「指定学生」，从本班启用名单勾选学生。转班或停用会在发布时拦截，需刷新名单重新选择。教练学情与学生任务列表均按发布时的接收名单显示。历史全班发布请求仍可重试。
