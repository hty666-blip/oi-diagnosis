# 直接代码讲解验收

日期：2026-11-02。基线 `abb4d9e`，目标为现有 MySQL 多语言分支与 PR #1。

## 需求与行为

按用户要求，辅导应当直接读取并讲解学生代码，而不是让初学者猜到一定提示层级才允许解释。已有源码时采用直接代码辅导，无源码的兼容路径仍保留原边界。

- 打开讲解即结合当前授权提交的代码、题目、编译器记录和执行结果分析。源码附行号，最多展示前 12000 字符，截断明确标注，不声称读取未提供部分。
- 可以直接指出相关语句及问题、解释语义和局部修改。反复“不会”时提高讲解细度，逐句拆解并用已有输入推演变量变化，不因困惑而暂停、记违规或要求凑失败提交次数。
- 引用学生原有代码不再因出现 `main` 就被当作代写。新的完整入口程序仍拒绝；原文匹配保留字符串字面量空白及 Python 缩进关系，局部修正允许展示。
- 模型缺失、输出无效或未引用实际代码时，明确提示未获得可用 AI 讲解，只展示可核对事实，不把模板伪装成分析。调用元数据记录非敏感回退原因。
- 编译失败时解释编译信息，AC 时可以继续问原理，不硬找错误。真实核验结果、绑定提交及掌握度不随讲解改变；历史证据失效仍显示待核对。

界面使用“讲解已提交的代码”入口，支持通过后的继续提问，显示当前代码编号；讲解按 Markdown 渲染代码块。正文加大，长回复从新讲解开头显示，不再自动跳到末尾一句问题。

代码编辑框换行继承现有缩进，括号中间换行展开内层，Python 冒号增加缩进。聊天 Enter 发送、Shift＋Enter 换行；中文输入法确认键不发送。已在隔离页面实际按键验证，并补充 3 项输入行为测试。
