# 初赛题库导入与暂存验收

日期：2026-11-10。状态：第一批导入和候选暂存已实现；题目审核编辑、正式发布、学生笔试作答和笔试 Agent 适配尚未实现。

## 使用入口

管理员登录后进入“平台管理 → 初赛题库”，点击“导入 ZIP 题包”打开弹窗。选择采集包，校验并保存预览；核对数量、复核事项和原题后，点击“确认暂存”。刷新或重新登录后，可从批次列表继续查看。

本地前端使用 5175，API 使用 18001。已将用户提供的 `csp_bank_v1.zip` 暂存到本地业务库：28 套试卷、1120 条原始题目、111 个题组、50 张图片、99 个叶子知识点；全部候选题状态为 needs_review，正式发布数为零。原始 ZIP/目录和真实环境配置未改写，原编程题库数量保持一致。

本模块保留全部原始记录，不使用来源 canonical_question_id 合并评分实体。因此 1120 是原始候选记录数，不是已经确认的独立题数量；也不沿用采集包“可练”的口径宣称已审核。

## 本批行为

- ZIP 支持根目录或单一外层目录。校验 UTF-8 JSON、清单摘要、唯一编号、题组双向归属、选项答案、知识点引用及先修关系无环；不抓取远端资源、不执行包内脚本、不解压写盘。
- 限制上传 16 MiB、展开后 64 MiB、512 个归档项、单文件 12 MiB、单图 4 MiB；拒绝越界路径、非规范分隔符、链接、加密/重复文件和摘要不一致的内容。
- 同一管理员重复上传相同字节的题包，恢复原批次。预览保存 24 小时，过期需重新上传；已暂存批次不按预览期限删除。
- 暂存与操作审计在一个事务中提交；重复确认不重复插题，失败整批回滚。所有来源状态都保留为原始值，系统候选状态统一为 needs_review。
- 分页查询题目，按试卷、题干/编号及复核标记筛选。核对弹窗显示共用程序、选项、来源答案与冲突答案、原始知识标签、标注建议、来源定位和图片。图片通过管理员认证接口读取，禁止浏览器缓存。
- 未核对答案、答案冲突、未知多选计分、去重关联、撤题线索和知识点建议分别记录。建议不覆盖原始标签，不自行裁定冲突答案。
- 学生、教师访问候选题、图片、上传和暂存接口均被拒绝；没有候选题发布或学生判分接口。

真实包中 25 条来源去重/变体关联均保留独立记录；5 条答案冲突、32 条未知多选计分规则、1 条撤题线索及 33 条明确关键词触发的标注建议进入复核事项。这些标记可能重叠，建议不是已经核实的知识结论。

手动查看还发现 `q_noip-j-2013_07` 的图示与选项考查数据结构，来源却标注网络协议。这说明不能只修复零覆盖项就认为标签可靠，正式发布前仍需逐题核对。

## 持久化与迁移

新增迁移 `o901b527d3ef`，承接 `n8fa0416c2de`：

| 表 | 用途 |
| --- | --- |
| written_import_batch | 管理员、文件摘要、预览/暂存状态、统计与快照元数据 |
| written_candidate | 按批次和原编号独立保存原始题目、规范化复核元数据及待审核状态 |
| written_import_asset | 图片路径、类型与摘要 |
| written_import_chunk | 快照与图片的有序数据块 |

真实题包曾触发 Windows/asyncmy 读取超大 JSON 单行时的连接错误。现将 JSON 快照压缩，快照和图片按不超过 24 KiB 的 Base64 文本块保存；读取时检查顺序、摘要和解压上限。缺块或损坏返回明确的 409，不提交半批题目。

升级为增加表，不改写原编程题、提交或对话。测试库已执行降级到 n8、重新升级到 o，并核对四张表的字段与模型一致。降级会删除新增候选表及其中数据，业务库不直接执行降级。

加密备份包含四张新表。仅对明确的 m7/n8 → o 结构开放兼容：为旧备份补空候选表，m7 另补空消息回执；保留新备份真实记录，拒绝其他结构缺失及未知未来版本。业务升级前已在 `data/private/` 保存并校验加密备份，密钥和备份未纳入 Git。
