# 管理员端第二批：题库与版本管理

## 使用流程

管理员进入“平台管理 → 题库管理”，可按题号、标题及上下架状态查询；打开题目查看来源、许可和最近 30 个版本。更早版本仍保留给历史提交和训练。

导入支持两种方式：下载 UTF-8 JSON 模板并填写，或选择仓库 `problems/` 中已审阅的自建题包。每批最多 20 题、8 MB，单题最多 2 MB；题面最多 20 万字符，正式测试最多 100 个，单份输入/输出最多 100 万字符；仓库测试文件另限 1 MB、累计 2 MB。仓库读取也限制文件大小并拒绝越界路径、错误配对、重复题号及无效资源限制。

JSON 必须包含 `problems` 数组。填写题号、题面、样例、来源、许可和资源限制；A/B 级还需审核人及正式测试，A 至少 3 个、B 至少 1 个。C/D 只使用公开样例，通过样例不能显示正式通过。模板的许可、审核人占位内容必须替换。错误会标明题目和测试位置。

核对来源、许可与使用权限后，点击校验预览。页面说明新增、追加或内容相同，并显示测试范围、数量及导入影响。校验只检查结构与声明，不能证明答案正确性或替代人工许可核对。

预览保存在服务器，30 分钟有效。确认只提交预览编号，不重新读取客户端内容或磁盘文件；其他管理员改变版本或上下架状态会使整批拒绝。网络不确定时可重试同一编号，不重复追加。新内容先下架，核对后独立上架；相同内容保留原状态，不追加版本。无可执行测试、缺来源许可或缺正式测试审核人的版本不能上架。成功操作写入脱敏审计。

## 版本与教学边界

- 版本保存题面、样例、正式输入输出、资源限制、来源、许可、审核人及摘要；只追加，不覆盖。后台判题读取数据库快照，不再根据磁盘最新内容重跑旧提交。损坏或缺失的快照停止执行，不退回最新数据。
- 训练保存时固定版本；保留题目的草稿编辑不自动升级。题目下架或版本更新后，旧草稿不能直接发布，需核对后新建训练。已发布训练保留原版本，不改名单、旧判定和教师审计。
- 下架阻止新的自由练习和新选题；已授权的原训练与历史提交修改仍使用原版本，班级/名单限制继续生效。师生档案、讲评案例、错题卡、历史标题和代码讲解也读取绑定快照。
- 学生题面显示版本标记。读取题面后若版本变化，提交会被拒绝并保留代码；继续历史提交保持原版本。点击“使用当前上架版本开始新练习”明确解除旧提交/答疑关联，保留编辑器代码并加载最新版。不同题目版本的 AC 不能关闭原答疑。
- 迁移 `l6d82c97041a` 为存量题目、提交和训练回填迁移时快照。它不能重建引入版本管理之前实际使用过的更早题面或测试；旧机器结果不改写。无法读取的旧测试标为不可用。

## 命令行与部署

先执行 `alembic upgrade head`，再启动 API。`import_problems.py` 和 `import_packages.py` 共用版本安装逻辑，不能再直接覆盖已绑定内容；默认新增版本待上架。自建题包可使用 `scripts/import_packages.py --publish` 明确上架本次新增/变化且已审阅的版本，不恢复管理员下架的相同版本。`prepare_demo.py` 使用这一规则准备自建演示题。

迁移后的历史判题无需原题包仍留在磁盘，但备份必须包含 MySQL 版本表。没有挂载仓库题包时，数据库题库仍可查询，仓库导入列表为空。正式使用中不要手工覆盖题库表。

工作树中的 `scripts/word_import/` 属于另一个任务，已保留且不纳入本批提交。它采用仅新增的旧导入兼容路径；后续集成时应对接正式版本导入，不直接覆盖已有题目。
