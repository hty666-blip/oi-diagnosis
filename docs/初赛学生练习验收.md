# 初赛学生练习与错题本

2026-11-17。学生登录后从左侧打开「初赛练习」，按 CSP-J/S、题型或题干关键词筛选已发布题目。提交前只显示题面、材料、选项与分值。提交后查看得分、本人答案及该版本的参考答案和审核解析。

## 作答与订正

- 单选按一个选项判分。多选按集合比较，选项顺序无关，漏选或多选得零分。判断按布尔值比较。填空按审核规则精确比较或忽略首尾空白。
- 未提交的答案保存在当前浏览器，按账号、题目及发布版本隔离。同一标签页刷新可恢复正在作答的题。题目变更时，旧答案仍可查看，由学生决定何时打开新版。
- 提交请求固定题目版本。服务器保存结果后，同一请求重试拿回原结果。题目已换版或下架时，未在服务器保存的旧作答会被拒绝。
- 每次有效作答均保留历史。某题最近一次答错就进入「待订正」，重新答对后进入「已订正」。改版或下架后，学生仍可回看自己的历史题面、得分和解析。订正状态只记录再答结果。

## 用原创题实践

在仓库根目录生成二叉树练习题包：

```powershell
python scripts/build_written_demo.py data/private/original_written_practice.zip
```

输出目录应已存在，文件名须未占用。用管理员打开「平台管理 → 初赛题库」，导入 ZIP 并确认暂存。逐题核对四道原创题的答案、解析和计分规则，填写答案核对依据与操作说明，确认使用范围并审核发布。学生可从「初赛练习」试做。业务题库的 1120 条真实候选须另行人工审核。
