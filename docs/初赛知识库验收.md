# 初赛知识库与答疑引用

## 管理和使用

管理员打开「平台管理 → 初赛知识库 → 新建知识条目」，选择已暂存题包与叶子知识点，填写标题、正文和资料来源。编辑稿可单独保存。发布前要填写审核说明，每次发布生成独立版本，可查看历次发布内容或下架条目。

学生在「初赛练习 → 知识库」按标题、知识点或编号查询，阅读已上架的当前版本与来源。管理员保存新稿时，学生继续阅读上一个已发布版本。

答疑从作答所用的题包批次匹配已发布条目，优先主知识点，其次按题目记录的顺序找次知识点。本轮最多引用一篇，长正文引用节选。旧会话保留当时使用的版本、内容和来源。下架后这篇文章退出知识库与新答疑引用。

## 真实模型实测

2026-11-17，在独立测试库使用自编二叉树题和测试账号调用已配置的 DeepSeek `deepseek-chat`。前两轮检查首次讲解和追问换例子，最后一轮检查实际引用人工发布的 v2 知识条目。共发出 6 次真实请求，均采用模型输出。网关统计输入 4429 token、输出 1175 token。

学生选了 B（8）。模型区分第 4 层的上限 8 与四层节点总数上限 15。第二轮用三层树的 1+2+4=7 举例。初次试测时讲解曾把可能的错因说成学生确实执行过的步骤。调整提示后，带 v2 知识条目的复测回到可核实的「你选了 B」，并提醒分清两种数量。规则得分始终是 0 分。实测覆盖这道原创题的三轮交互。

## 从讲义进入练习

学生阅读条目时，文末列出最多六道同题包、同主知识点的已上架练习。题目使用当前审核版本，重标或下架后会更新。学生可以直接作答，在同一页面返回原讲义。
