# 管理员端第一批：账号、班级与审计

## 使用流程

管理员登录后默认进入“平台管理”：管理首页、账号管理、班级管理和操作审计。教学工作台、学生档案及诊断复核仍可直接进入。

1. 在班级管理创建班级，记录稳定编号，选择负责教练。一个教练可负责多个班；学生只有一个当前班。
2. 创建学生、教练或管理员账号，设置临时密码。学生可在创建时分班；教练在班级管理分配。新账号首次登录必须改密，服务端也限制其业务操作。
3. 批量创建先下载 CSV 模板，填写 `username,display_name,role,password,class_id`。每次 1–100 行，班级填写编号，教练和管理员留空。预览显示接收账号、分班及重复错误；确认时重新校验，整批成功或整批不导入。临时密码不写入浏览器草稿。
4. 转班先预览旧班已发布任务影响，再确认。学生不会自动加入新班已有发布名单；旧班训练、讲评和反馈不再对其开放，数据库记录及原名单保留。转班撤销旧登录。
5. 更换教练时，明确选择保留原训练归属，或将不再负责本班的教练名下训练转交给一名保留的负责教练。转交保留原始创建人、提交、讲评和复核历史；未转交的任务由管理员管理。

账号列表支持姓名/用户名查询、班级名单筛选及分页。停用保留记录并撤销登录；恢复不恢复旧令牌。重置密码后必须使用新临时密码登录并再次改密。本人改密也撤销其他旧登录。最后一个启用管理员不能停用或降级。
