# 初赛简答与教师复核

1. 管理员在「平台管理 → 初赛题库」导入[原创简答演示包](../examples/written/oi-written-short-demo.zip)，核对题面、参考答案与评分要点后发布。每题配置 1 至 8 个要点，分值为正整数，合计须等于题目分值。
2. 教练在「初赛任务」把新题发布给班级。学生在「初赛练习 → 班级任务」提交简答。每个专项的每道简答只交一次；「待复核」没有分数，暂不显示参考答案。
3. 教练从专项学情点开「待复核」。题干、原作答、参考答案及评分要点均使用提交时版本。逐项给分、填写反馈、预览，然后确认发布。发布后学生可在任务或作答记录查看各项得分、解析与反馈。

## AI 草评

教练可选择「生成 AI 草评」。草评 Agent 给出建议分和原文引用，服务端检查分值与引用后，独立复核 Agent 再核对建议。只有通过两步的建议才可填入评分表，教师可调整。模型请求不带账号和班级标识；含图片或过长题干的简答由教师直接评分。模型关闭、超时或未通过复核时仍可提交人工评分。旧的处理租约到期后允许重试。

班级学情分别显示待复核、满分、未满分和未交。简答目前只在班级任务作答，含简答的试卷不进入客观题限时模拟。简答成绩不纳入逐题错题本和学习路线。

## 验收

- 独立 MySQL 专项 33 项、前端 83 项和构建通过。覆盖越权拒绝、版本固定、超分拒绝、重复确认和旧备份恢复。
- 真实模型仅使用公开原创题和合成作答。两次角色调用分别确认第一项 2 分、第二项 0 分，共用输入 707 token、输出 182 token。
- 在独立桌面环境，学生提交后显示待复核；关闭模型时，教师仍可发布 2 / 4 分，学生回看同一份作答的逐项分数和反馈。
