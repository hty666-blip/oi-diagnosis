## 2. 论文结构（6 章）

### 第 1 章 绪论（约 3000 字）

- 1.1 背景：CSP-J/S 参与人数增长、教练资源稀缺、初学者错误密度高
- 1.2 问题：OJ 只给 verdict；题解面向"已会的人"；通用 LLM 会讲错且直接给代码
- 1.3 研究内容：以"可验证证据"约束 LLM，构建错题诊断流水线
- 1.4 主要工作（4 条，对应本文贡献）
- 1.5 论文组织

**贡献表述（可直接用）**：

1. 提出**机制 × 性质双轴错因模型**，把"错在哪"与"错多深、该谁管"分离；
2. 设计**证据闸门**机制：机制层结论必须绑定可复现证据，把幻觉控制从提示词转为代码约束；
3. 实现**反例最小化**流水线（ddmin + validator），把上万行测试点缩到可手算规模；
4. 构建**规则优先的分诊 + 模型兜底**架构，并用消融实验量化两者的分工边界。

### 第 2 章 相关工作（约 3000 字）

- 2.1 自动程序修复（APR）：Agentless / SWE-agent / ChatDBG 的定位—修复范式
- 2.2 教育类编程助手：CodeAid 的"不直接给答案"、EduChat 的中文教育对话
- 2.3 知识追踪：BKT / DKT
- 2.4 差距总结：现有工作缺少"面向 OI 的错因本体 + 可验证证据链"

> 注意：写作时**只描述设计理念，不引用无 license 项目的代码**（EduChat/CodeAid 均无 license）。

### 第 3 章 系统设计（约 6000 字，核心章）

- 3.1 总体架构（分层图：接入 / 应用 / 编排 / Agent / 能力 / 数据）
- 3.2 错因双轴模型（M01–M11 × P0–P5 表）
- 3.3 诊断流水线（Triage → 取证 → 诊断 → 评审 → 教学）
- 3.4 证据模型（6 类证据 + digest + 可复现标记）
- 3.5 提示阶梯状态机（L0–L4，四条硬规则）
- 3.6 反例最小化（ddmin + 结构感知适配器 + validator）
- 3.7 置信度与闸门（阈值 0.75、LLM 封顶 0.6）
- 3.8 数据库设计（8 张表）

### 第 4 章 关键技术实现（约 4000 字）

- 4.1 沙箱执行层：go-judge（生产）与 DockerRunner（开发兜底）的接口抽象
- 4.2 表层错误检测：字符串/注释感知状态机（全角标点只改代码区）
- 4.3 编译报错映射：37 条规则 → 学生语言
- 4.4 编排引擎：LangGraph 状态图 + 自研预算/证据闸门
- 4.5 模型网关：超时/重试/降级，key 不入日志
- 4.6 前端：三页 + Vite 代理

### 第 5 章 实验与评估（约 4000 字，数据见 §3）

- 5.1 实验环境（Windows 10 + WSL2 + Docker，PG16+pgvector，DeepSeek-chat）
- 5.2 分诊评测（200 条 fixtures）
- 5.3 反例最小化（5 个错解）
- 5.4 端到端诊断（150 条构造集）
- 5.5 消融：规则 vs 规则+模型
- 5.6 案例分析（3 个 LLM 兜底案例）
- 5.7 局限与威胁效度

### 第 6 章 总结与展望（约 1500 字）

- 结论、不足（构造集、单机、C++ 限定）、后续（真实样本、多语言、校本部署）

## 7. 预判提问与回答

| 问题 | 回答要点 |
|---|---|
| **多 Agent 是不是过度设计？** | 消融证明：规则覆盖 88% 场景（59ms/¥0），模型只补 12%；如果只用单一模型，成本和时延都翻 10 倍且不可解释 |
| **模型说错了怎么办？** | 三道闸门：Schema 强制绑证据、置信度 ≤0.6、不直接给学生只进教练队列；代码类输出必须编译通过 |
| **反例最小化会不会产生非法输入？** | 结构感知重建（n/T 与元素数同步）+ validator 二次校验，本次 5/5 全部合法 |
| **为什么不用 go-judge？** | 用了，生产路径就是它；本机 WSL 内核 clone 返回 EAGAIN，五种方案都试过，所以抽象出 DockerRunner 兜底——这也说明执行层抽象是必要的 |
| **数据哪来的？版权怎么算？** | 58 题来自洛谷/GESP，仅本地演示、不进版本库、界面标注来源；自建 2 道 A 级题包可分发；论文不附题面 |
| **准确率 100% 可信吗？** | 不可信，这是构造集。真实学生分布会显著下降，已在论文"威胁效度"一节写明，并计划用双评真实样本重测 |
| **创新点是什么？** | 不是"用了 Agent"，是"用证据约束生成"——把可验证性做进类型系统 |
