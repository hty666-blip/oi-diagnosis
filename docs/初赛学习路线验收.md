# 初赛学习路线

学生从「初赛练习 → 学习路线」查看本人最近 100 次作答涉及的主知识点。按题包、级别和主知识点分别统计，展示作答次数和题包登记的直接先修知识（最多五项）。历史作答使用当时发布版本的知识点。

答错后标为「待巩固」，可打开原作答或做一道系统推荐的新题。推荐仅从同题包、同级别、同主知识点的当前已发布题目中选取，排除本人曾做过的题和题包标明的完全重复题。没有候选时显示「暂无新题推荐」。

重做原题答对后，错题本可标为已订正。学习路线只有在另一个练习的首次作答正确后才显示「新题答对」。同知识点再次答错会重新进入「待巩固」。页面使用真实作答和规则判分，单次结果只代表相应练习。

## 验收

- 独立 MySQL 专项 67 项通过，覆盖学生本人权限、同题重做、完全重复题、窗口之外的旧作答、题包与级别隔离、下架及更新主知识点。前端 83 项、生产构建与 Ruff 检查通过。
- 电脑浏览器使用自编二叉树题实测空白路线、单选答错、从路线打开原作答、重做答对、推荐另一道多选并首次答对。刷新后查看 3 次作答及「新题答对」。[验收截图](images/written-progress.jpg)
- 复用现有作答与题目版本，无数据库结构迁移。新增发布版本保存简短的主知识点信息。旧版从冻结题面读取，推荐兼容路径每次最多扫描 100 条旧版候选。
