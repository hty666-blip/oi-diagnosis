# 初赛错题诊断与答疑

2026-11-17。学生在「初赛练习 → 作答记录」打开一道答错的题，点击「讲解这道错题」或输入自己的问题。Enter 发送，Shift+Enter 换行。刷新可继续同一份作答的答疑。

## 两位 Agent 如何协作

1. 服务端取本人作答及提交时对应的审核快照，计算确定的选项或文本差异。后续题面修改与下架不改变这份材料。
2. 诊断 Agent 根据差异、审核答案和学生问题，输出可能的错因、下一步讲解重点、依据编号。可以保留未知。
3. 答疑 Agent 通过第二次独立请求收到这份交接，结合审核解析回答当前问题。每轮角色来源和引用可在「查看诊断交接与依据」核对。平台运行记录分别统计初赛诊断和答疑的模型使用情况。

模型跟随平台配置，只在学生主动提问时调用。材料包括本次题目、作答、审核解析和有限的同题追问。模型不接收账号编号、用户名或其他同学记录。题图仍可在结果页查看，当前模型请求只使用文字材料。

模型未启用、超时或引用无效时，结果页显示规则比较、审核解析及原因。二叉树原创题有一份版本化知识卡，追问可用更小的例子解释层数、节点和边。其他题使用自己的审核解析。知识卡目前只关联原创二叉树题，完整知识库和教师知识条目管理仍待建设。

## 保存与恢复

答疑按作答编号关联本人，重复请求复用已保存的回复。模型等待期间不持有数据库写锁。同一道错题同时只处理一个请求，断开后可刷新记录，超时后凭原追问继续。初赛规则评分始终由作答模块给出。
