# 初赛题库知识点覆盖

管理员从「平台管理 → 初赛题库」查看已暂存批次，打开「知识点覆盖」。表格保留目录中的零题知识点，列出 J、S 的待审数与上架数、未分级待审数和当前讲义版本。

待审数按候选题原始主标签统计。「看待审题」返回候选列表，并应用同一主标签和待审核筛选。上架数按当前已审核发布的题面计算，改标签或下架后更新。讲义列只有已上架的审核版本。可按名称、编号、无上架题或无已发布讲义筛选。

## 验收

- 独立 MySQL 43 项通过，涵盖旧题面版本、改标签和级别、下架、零题节点、未分级、讲义版本及管理权限。前端 83 项、构建与 Ruff 通过。
- 桌面以原创题包验证前缀和的 1 道待审、1 道上架、讲义 v1。两种缺项筛选会排除该知识点，「看待审题」只返回对应题目，清除知识点筛选后恢复到 15 道待审题。[验收截图](images/written-knowledge-coverage.jpg)
- 对本地 1120 道采集候选只读复算，逐项与冻结的原始记录核对一致。99 个叶子中 75 个有待审题作为主标签，24 个没有。另有 15 道题的主标签未落到叶子。上架为 0。本口径只看主标签和状态，与采集报告按主次标签统计的覆盖数用途不同。
