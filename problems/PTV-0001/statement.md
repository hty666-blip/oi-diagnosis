# PTV-0001 求和

## 题目背景

小 A 刚学完循环，老师让他求一堆数的和。

## 题目描述

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$，求它们的和。

## 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个整数之间用一个空格隔开。

## 输出格式

一行一个整数，表示所有数之和。

## 样例

### 样例 1 输入

```
1
5
```

### 样例 1 输出

```
5
```

### 样例 2 输入

```
2
-3 1
```

### 样例 2 输出

```
-2
```

## 说明/提示

**数据范围**

- 对于 $100\%$ 的数据，$1 \le n \le 10^5$，$-10^9 \le a_i \le 10^9$。

**注意**：答案可能超过 `int` 范围，请使用 `long long`。
