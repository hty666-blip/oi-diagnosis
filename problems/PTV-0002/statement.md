# PTV-0002 阶乘

## 题目描述

给定 $T$ 个正整数，对每个数 $n$ 输出 $n!$（$n$ 的阶乘）。

## 输入格式

第一行一个整数 $T$，表示数据组数。

接下来 $T$ 行，每行一个正整数 $n$。

## 输出格式

输出 $T$ 行，每行一个整数，表示对应 $n$ 的阶乘。

## 样例

### 样例 1 输入

```
2
3
5
```

### 样例 1 输出

```
6
120
```

## 说明/提示

**数据范围**

- $1 \le T \le 1000$
- $1 \le n \le 20$

**注意**：$20! = 2432902008176640000$，远超 `int` 范围，请使用 `long long`。
