# 原创初赛演示包

本包包含自编的 J、S 两组练习，各 8 题，每题 2 分。覆盖 8 个知识点、四种客观题和一组共用 C++ 代码。题面、答案和解析位于 [源稿](demo_bank.json)，配套讲义见 [知识条目](知识条目.md)。

## 生成和导入

可直接使用 [oi-written-demo.zip](oi-written-demo.zip)。修改源稿后，在仓库根目录执行 `python tools/build_written_demo.py --output examples/written/oi-written-demo.zip` 重新打包。工具会先通过项目的题包校验。

1. 管理员打开「平台管理 → 初赛题库」，上传 ZIP，预览并暂存。
2. 逐题核对答案、题型、分值及解析。在「答案核对依据」写入本项目原创题的具体核对结果，确认教学使用权后发布。候选题初始为待审核。
3. 在「平台管理 → 初赛知识库」选择此批次和同名知识点，录入审核过的讲义及来源，再发布。

## 一条演示路线

教练从「初赛任务」给班级发布两道二叉树题。学生在第一道多选只选择第 5 层的最大节点数，交卷后打开错题答疑。随后从同一专项打开判断题，选择「错误」。返回学习路线查看「新题答对」。教练回到专项学情，可核对两次交卷和一题答对。

这两组题是本项目原创演示练习，级别用于演示筛选。仓库中的这份包只包含自编题和解析。

简答可用独立的[原创简答包](oi-written-short-demo.zip)，按相同流程审核后由教练发布班级任务。修改[简答源稿](short_demo.json)后运行 `python tools/build_written_demo.py --source examples/written/short_demo.json --output examples/written/oi-written-short-demo.zip` 重建。逐项给分演示见[简答验收](../../docs/初赛简答复核验收.md)。

## 验收

独立 MySQL 逐题走通暂存、审核、发布和作答，16 道题均按审核答案获得 2 分。前缀和的两道子题都能读取共用代码。

前缀和填空题另用 DeepSeek 实测一例。学生填 4，并说明计算的是 p[4]−p[2]。两位 Agent 分别收到共用程序、已发布讲义 v1 及规则给出的 0 分，答疑 Agent 同时收到诊断交接。修正填空题的措辞后，答疑明确写「你填了 4」「你提到用了 p[4]−p[2]」，并推导 p[4]−p[1]=2。两轮共 4 次模型请求，全部采用结果，输入 3417 token、输出 877 token。
