# 原创初赛演示知识条目

每节可作为一篇初赛知识条目。管理员选择原创演示题包和对应知识点，将本节标题及正文填入草稿。来源可填「OI 错题诊断项目原创知识条目」及节名。审核发布后，学生和答疑 Agent 可以引用。

## 二进制位权与无符号范围

二进制整数最右边的位权为 1，向左每移一位，位权翻倍。将所有数字为 1 的位对应的位权相加，就得到十进制数。比如二进制 11001 对应 16 + 8 + 1，也就是 25。

使用 k 位表示无符号整数时，有 2^k 种编码，覆盖 0 到 2^k − 1。以 3 位为例，编码从 000 到 111，最大值为 7。编码数量包含零，所以最大值比编码总数少 1。题目如果指定有符号表示，应先确认编码规则。

## 二叉树层数与节点数

二叉树中的每个节点最多有两个孩子。根在第 1 层时，第 h 层最多有 2^(h−1) 个节点。把第 1 层到第 h 层的上限相加，可得整棵树的上限 2^h − 1。

例如根为第 1 层、最深节点在第 3 层，三层的上限依次是 1、2、4，共 7 个节点。要到达第 3 层，至少存在一条经过 3 个节点的根到节点路径，节点总数也可以只有 3。阅读题干时先确认它问的是某一层、整棵树还是到达指定层所需的最少节点数。高度如果按边数计算，要先换成层数。

## 栈与队列

栈后进先出，最后压入的元素在栈顶。队列先进先出，最早入队且未取出的元素在队首。

依次放入 6、2，取出一个，再放入 9。若用栈，先取出 2，此时下一次取出 9。若用队列，先取出 6，下一次取出 2。遇到交错的加入和取出操作时，按顺序写下每一步的结构内容，并标出哪一端可以取。

## 进程状态与存储

在简化的进程状态模型中，运行态表示正在用 CPU。就绪态表示具备运行条件，正在等待 CPU。阻塞态表示正在等待输入输出等事件，事件完成后可以进入就绪态。

例如进程等待键盘输入时，操作系统可安排另一就绪进程运行。打开的程序可以同时有存放在普通易失性内存中的工作数据，以及已落盘的文件。计算机断电后，重新打开已保存的文件依靠持久存储。题目涉及保存结果时，留意数据是否已经写盘。

## 前缀和与区间端点

对下标从 1 开始的数组，令 p[0] = 0，p[i] 为前 i 个元素的总和。区间 [l, r] 的和为 p[r] − p[l−1]，减去的是区间左端之前的前缀。

例如数组为 [5, −1, 6]，前缀依次是 0、5、4、10。区间 [2, 3] 的和是 10 − 5 = 5。区间 [1, 2] 使用 p[0]，得到 4。处理负数时仍然使用同一个公式。将 p[r] 和 p[l−1] 各自包含的下标写出来，便于核对端点。

## 有向无环图与拓扑序

拓扑序要让每条有向边的起点排在终点之前。如果边表示课程的先修关系，拓扑序就是一种可行的课程安排。同一张图可以有多个拓扑序。

例如只有 U→W 和 V→W，则 U、V、W 与 V、U、W 都可行。Kahn 算法可以用队列保存当前入度为零的节点，每取出一个就减去其后继的入度。仍有节点而队列已空时，剩余节点组成的子图含有向环。沿环检查每条边可看出矛盾，最后要求某节点排在自己之前。

## 二分查找的左边界

在非降序数组中，谓词「元素不小于 x」从假变真后保持为真。二分查找的左边界是第一个满足这个谓词的下标。探测位置的值小于 x 时，排除它和它左边的元素。其余情况继续寻找左侧边界。数组下标从 0 到 n−1 时，找不到可返回 n。

例如 [2, 4, 4, 7] 中，第一个不小于 4 的下标为 1，第一个不小于 5 的下标为 3，查找第一个不小于 8 返回 4。可以用重复元素、空数组、阈值分别落在首尾外侧的输入检查边界。

## 循环次数与渐近复杂度

先数最内层操作执行多少次，再看规模增大时的增长速度。内层每次范围相同，可以相乘。如果每轮范围依赖外层下标，就对实际执行次数求和。

例如外层变量 i 从 1 到 n，内层执行 2i 次，累计 n(n+1) 次，时间增长量级是 n²。若单个循环中的变量从 1 开始反复乘 3，直到超过 n，则次数随 n 的对数增长。计算额外空间时单独统计额外结构的最大占用。重复使用的少量局部变量不会因执行次数多而扩大空间占用。
