# 数据说明

本目录提供项目使用的题面和标签，方便查看数据格式及复现导入流程。

| 路径 | 内容 | 用途 |
| --- | --- | --- |
| `problems/*.json` | 采集的洛谷题面、样例、标签与来源信息 | `scripts/import_problems.py` 导入 |
| `problems/raw/*.html` | 部分采集页面的原始快照 | 检查解析结果与来源 |
| `gesp/*.json` | 从 GESP 题面材料转换的结构化记录 | 导入时指定 `--dir data/gesp` |
| `tags.json` | 标签映射 | 辅助题库分类 |

仓库根目录的 `problems/PTV-*/` 为自建正式题包，包含题面、标准程序和成对输入输出。`eval/` 保存构造评测集与历史报告；历史评测报告不能作为真实教学效果的证明。

采集题面与页面快照的版权归原平台及出题人，来源信息以记录中的字段和原页面为准；这些材料不适用自建题包的 CC BY-SA 4.0 许可。本项目未为采集内容授予新的许可。

题面和公开样例不等于正式测试数据。只有明确标记并实际加载的自建题包测试能够产生正式范围的 `AC`。

`run/`、后端运行目录、真实账号数据与本地密钥不纳入数据集。
